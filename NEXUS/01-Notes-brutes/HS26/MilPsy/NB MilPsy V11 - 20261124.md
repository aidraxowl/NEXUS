## 02) Critères de qualité (S. 19–37)
- !! [[Critères de qualité des tests|==Testgütekriterien==]] : critères de qualité des procédés de diagnostic psy. ; doivent être décrits et documentés ds les manuels de test ; organisation hiérarchique (engrenages : objectivité -> fidélité -> validité)
- !! ==Hauptgütekriterien== :
  - ==Objektivität== : résultats indépendants du ==Testleiter== ?
  - ==Reliabilität== : le test donne-t-il des résultats fiables ?
  - ==Validität== : mesure-t-il ce qu'il doit mesurer ?
    - ==prognostische Validität== : qualité de prédiction ?
    - ==inkrementelle Validität== : gain d'info p/r à d'autres procédés ?
    - ==Konstruktvalidität== : démarcation empirique p/r à d'autres procédés ?
- Corrélations pr se faire une idée (==prädiktive Validität==, S. 21) : violence ds les médias -> agressivité .13 ; anti-inflammatoires -> douleur .14 ; critiques de films -> recettes .17 ; mammographie -> cancer du sein ds 2 ans .27 ; Viagra -> fonction sexuelle .38 ; taille -> poids .44 ; analyses labo -> cancer du poumon .48 ; distance à l'équateur (USA) -> température moyenne .60
  - -> un r de .30 en sélection n'est pas « faible » (mon interprétation)
- !! « ACHTUNG : tests à NE PAS utiliser » (S. 30–37)
  - ==Graphologie== : > 200 études -> aucun lien écriture–personnalité, aucun lien écriture–réussite pro (Kanning 2015) -> « totalement non sérieux »
  - ==Dimensionstests== (Big Five -> NEO-FFI, MMPI, BIP) ≠ ==Typentests== (DISG, Myers-Briggs, Reiss-Profil)
  - bcp de méthodes répandues pas vérifiées scientifiquement
  - ==Selbsteinschätzung== -> sujette aux biais
  - ==DISG== (dominant, initiatif, stable, consciencieux) : infos de qualité manquantes (objectivité, fidélité, validité) ; classement en types de couleur -> pensée stéréotypée -> !! fortement déconseillé (Kanning 2015)

## Sélection : bases (S. 42–…)
- ==Eisberg-Metapher== : visible = comportement et résultats ; ligne de flottaison = compétences ; invisible = capacités, savoir-faire, motivation, personnalité, savoir, intellect
- ==Passung== (Schreyögg 2005) : ==Person-Job Fit==, ==Person-Organisation Fit==, ==Person-Group Fit==, ==Person-Supervisor Fit==
- !! [[Approche trimodale du diagnostic|==Trimodaler Ansatz==]] (Schuler) :
  - ==Eigenschaften== -> tests : questionnaires de personnalité, tests d'intelligence, inventaires de motivation
  - ==Verhalten== -> simulations : AC, ==Arbeitsprobe==
  - ==Ergebnisse== -> approches biographiques : CV / références, certificats, interview
- Premiers tests d'aptitude mil. : ==Army Alpha== (1917, USA, écrit, pr recrues avec bon anglais ; la slide dit aussi « pr analphabètes » ?? sans doute erreur) ; ==Army Beta== (non verbal, images / motifs / symboles, pr analphabètes ou anglais faible)
- !! Validités (Sackett et al. 2022), sélection :
  - interview structurée .42 ; test de connaissances pro .40 ; questionnaire biographique (pondération empirique) .38 ; ==Arbeitsprobe== .33 ; !! test cognitif .31 ; test d'intégrité .31 ; intelligence émotionnelle (perso) .30 ; !! AC .29
  - SJT .26 / .26 ; conscienciosité contextualisée .25 ; intérêts .24 ; stabilité émotionnelle contextualisée .23 ; IE (capacité) .22 ; bio (rationnel) .22 ; extraversion contextualisée .21
  - conscienciosité .19 ; interview NON structurée .19 ; agréabilité contextualisée .19 ; ouverture contextualisée .12
  - extraversion .10 ; agréabilité .10 ; stabilité émotionnelle .09 ; expérience pro en années .07 ; ouverture .05
  - -> Big Five « nus » = validité faible ; « contextualisés » (formulés pr le contexte de travail) nettement mieux
- ==Anforderungsbereiche== (Amelang & Schmidt-Atzert 2012) :
  - personnalité (Big Five, motivation et valeurs, stabilité émo.) -> comportement, résistance au stress, style de conduite
  - capacité cognitive (intelligence, résolution de pb, créativité) -> prédit perf., apprentissage rapide, adaptabilité
  - compétence sociale (comm., empathie, esprit d'équipe) -> perf. d'équipe, cohésion, confiance, motivation
- Recherche : études très variées mais souvent trop spécifiques (peacekeeping, forces spéciales, planification tactique) ; ce qui compte = combien de pouvoir prédictif ont Big Five et capacité cognitive ; méta-analyses = conclusions + robustes (Sackett 2022)
- !! Profils de personnalité pr l'aptitude à l'engagement :
  - ouverture -> adaptabilité, créativité, apprentissage -> agir flexible, changer vite de schéma (Hyllengren 2017 ; LePine et al. 2000)
  - conscienciosité -> discipline, fiabilité ; trop élevée -> surcontrôle, peu de flexibilité -> « optimales Mass » : soigneux mais pas rigide (Pulakos et al. 2002 ; Salgado 1997)
  - extraversion -> confiance, effet de conduite, cohésion ; associée au succès du chef -> moral (Shamir et al. 2000 ; Judge et al. 2002)
  - agréabilité -> coopération, esprit d'équipe, gestion des conflits ; important en peacekeeping (Nkewu & Van Dyk 2016 ; Van Vugt & Kret 2018)
  - !! stabilité émo. = prédicteur le + fort : résilience, résistance au stress (Hyllengren 2017 ; Barrick, Mount & Judge 2001)
  - ?? contraste avec Sackett (stabilité émo. .09) : le tableau parle d'aptitude à l'engagement, Sackett de perf. au travail en général -> demander
- Capacité cognitive et réflexion :
  - ==General Mental Ability== : prédicteur stable de perf. au travail et en engagement (Hambrick et al. 2024 ; Burgoyne et al. 2024) ; adaptation et apprentissage ↑
  - traitement de l'info / pensée en réseau : vue d'ensemble, priorisation, changement de perspective (≈ flexibilité cognitive)
  - concentration / contrôle de l'attention : prédit perf. de drill et multitâche (Zanesco et al. 2025)
  - réflexion : décisions ↑, crédibilité ; biais ↓, prise de perspective ↑ (Criado-Perez et al. 2024)

## 03) Assessment Center (S. …)
- Histoire : de la sélection des officiers à l'AC -> « objectivation de la connaissance pratique des hommes », contrôle des aspects irrationnels, ==Demokratisierung der Offiziersauswahl==
- !! [[Assessment Center|==AC==]] = observation systématique de comportements pertinents pr la réussite, ds des situations proches de la pratique et critiques -> ==kontrollierte Subjektivität== ; but : image d'ensemble du candidat pr prédire les perf. futures
- Exercices types : études de cas, simulations d'entretien, tests de perso et cognitifs, interviews standardisées
- AC existants (armée) :
  - ==ACABO== / ==ACABU== : 2 j, 20–30 participants, 2×/an, 1 modérateur + 2 assesseurs ; dimensions analyse, autoréflexion, présence, communiquer, coopérer, influencer ; exposé court, jeux de rôle 1 & 2, cas courts, étude de cas, présentation, interviews 1 & 2
  - AC Gst Of : ½ j, 6–10 pers., 6×/an, 2 assesseurs ; analyse, autoréflexion, présence, communiquer, comportement social ; jeux de rôle 1 & 2, étude de cas, présentation, interview
  - ACAVA : 1 j, env. tous les 3 ans ; + gestion de conflits, conduite ; exposé, négociation (groupe), jeu de rôle, cas, interview
  - AC UNMEM : 1 j, 4×/an ; pensée globale, compétence perso, contact, équipe, négociation
- !! Nouveau : ==POTAK== Assessment
  - assessment individuel, 3 assesseurs ; image cohérente du candidat (simulations de comportement + questionnaire de perso + test cognitif) -> = trimodal (mon lien)
  - contenus + généraux qu'ACABU/ACABO (« chef mil. » et « subordonné direct » ; cas en contexte général)
  - l'équipe d'assesseurs décide du résultat
  - déroulement env. 5 h : accueil (présentation, déroulement, protection des données) ; 0700 étude de cas (5' + 15' + 5–10' réflexion) ; 0800 simulation d'entretien 1 ; 0845 simulation 2 ; 0930 présentation (40' prépa) ; 1100 interview 30–60'
  - dimensions : ==Analysekompetenz== (traitement de l'info) ; ==persönliche Kompetenz== (stabilité émo. et résistance, flexibilité, motivation à la perf. et à la conduite) ; ==Sozialkompetenz== (contact, coopération, ==Durchsetzungsvermögen==)
  - exercices : ==Fact Finding== ; 2 simulations d'entretien ; présentation « tactique de négo en contexte mil. » ; interview (avec résultats du questionnaire de perso)
- AC Gst Of : exigences = présence, traitement de l'info, communiquer, comportement social, motivation et autoréflexion
  - déroulement possible : matin ==PEP== (psychologische Eignungsprüfung) à la FAI, ~0800–1200 ; puis MILAK ~1345–2030 : étude de cas, entretien de conflit I, exercice de groupe ou conflit II, interview, problème
  - dès 2028 : ==Avanti Gst Of S==, intégré ds le ==MEP==
- !! Critères de qualité d'un AC :
  - analyse systématique des exigences (bcp de ==Stakeholder== ; participation -> engagement ; communication transparente ; signal clair sur ce qui compte pr réussir comme chef, p. ex. « conduite orientée vers l'humain », caractère, valeurs)
  - processus systématique : !! ==strikte Trennung zwischen Beobachtung und Beurteilung== : 1 observer, 2 décrire, 3 évaluer, 4 discuter
  - ==Mehraugenprinzip==
  - assesseurs formés (idéalement chefs hiérarchiques + psychologues) : validité pronostique ↑ avec psychologues (Gaugler et al. 1987) ; managers + précis que des étudiants (Lievens 2001) ; managers surtout moins bons SANS formation (Wirz et al. 2013)
  - exercices réalistes, orientés comportement : provoquer assez de comportement pertinent ; simulations + autres méthodes ; orientés buts et culture de l'org. ; ne favoriser personne ; standardisation max. -> niveau hiérarchique suivant, estimation juste du potentiel de conduite
  - ==Verhaltensanker== : chaque dimension définie par des comportements observables ; ex. « Kooperieren » : approprié (vise but et consensus, tient compte des autres, soutient, aborde les conflits, critique de façon factuelle) ≠ inapproprié (déloyal, trop coopératif, ignore les autres, soutien précipité/paternaliste, évite les conflits, se focalise sur le négatif ou ne critique jamais) ; + « non observable »
  - ==multiple Abdeckung== : chaque dimension observée ds plusieurs exercices (matrice exercices × dimensions)
  - -> ==kontrollierte Subjektivität==
- Rapport / feedback : entretien perso ; comportement réussi discuté en détail ; chefs hiérarchiques impliqués ; pistes de développement ; base pr coaching -> équité et ==Wertschätzung==, autoréflexion, message clair sur le comportement de conduite attendu
