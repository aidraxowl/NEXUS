## Sociologie : déf.
- Mot d'Auguste Comte (1798–1857) : *socius* (compagnon) + *logos* (science)
- Naissance <- Lumières (XVIIIe : absolutisme/féodalité -> démocratie, droits de l'homme), montée bourgeoisie, Révolution française
- Objet : société, vie en commun
- But : comprendre société, processus, changement (causes, déroulement, tendances)
- Condition : ==kritische Distanz==

4 questions de base
1. individu ↔ société, État, institutions, organisations ?
2. cohésion des sociétés complexes (fonctions d'intégration) ?
3. transmission valeurs / normes ?
4. pq le pouvoir, quelles formes légitimes ? (-> V10 Macht/Herrschaft)

## ==dreidimensionaler Aufbau==
- Niveaux d'agrégation (micro -> macro) : action soc. -> rôle -> groupe -> organisation -> institution -> société
- Processus : communication, interaction, stratification, valeurs/normes, socialisation, contrôle soc., conflit, pouvoir/influence, coopération, échange
- Domaines d'objet : pol., écon., éducation, armée, famille, médecine, jeunesse, science, religion…
- -> socio. militaire = un domaine d'objet, analysé à tous les niveaux

## ==Richtungen der Soziologie==
| | Socio. classique | Sociobiologie |
|---|---|---|
| Écoles | interactionnisme symbolique (recherche de sens) ; fonctionnalisme (ex. fonction famille) ; théories du conflit (conflit structurant) | sociobiologie (sexualité, agression, dominance) ; psycho. évolutionniste |
| Image de l'homme | être de culture, façonnable | comportement fixé génétiquement |
| Tendance | optimisme : société améliorable | pessimisme : « l'homme est comme il est » -> risque darwinisme soc. |

## Notions de base
- Carte sur 2 axes : explicite ↔ implicite / émotionnel ↔ cognitif
  - explicite-cognitif : ==Meinungen==, ==Einstellungen==
  - implicite-émotionnel : ==Bedürfnisse==, ==Motive==
  - au centre : ==Werte== + ==Normen== -> orientent tout le reste
- « Social » en socio. = neutre, tout comportement entre humains ≠ sens moral (philanthropique) ≠ sens pol. (socialiste)
- Même acte, sens ≠ selon contexte (baptême, ordalie de la sorcière, ==Gautschen== des typographes) -> sens d'une action = social

## Normes et valeurs
- Normal = ce qu'une société juge normal à une époque -> relatif, change
- [[Norme sociale]] : attente contraignante de la société envers l'individu, consigne d'action
  - ==Entlastungsfunktion== : oriente au quotidien, pas besoin de tout peser, anticiper les autres -> ordre soc.
- [[Changement de valeurs|Valeur]] : représentation générale, partagée, du désirable
- Formes de normes : interdits, ==Sitten==, ==Gebräuche==, lois -> tjs basées sur des valeurs
- !! Société ouverte : normes jamais fixées une fois pr toutes -> ==Legitimationsdruck== permanent -> base du [[Changement de valeurs]]
- Ex. cours : « être le seul à faire autrement, c'est un sentiment bête » -> pression de conformité

## Changement social
- !! [[Changement social]] (==sozialer Wandel==) = transformation de la structure soc. : rapports de pouvoir, valeurs/normes, structures familiales, communication, organisations, institutions
- souvent imprévisible, non voulu, longue durée
- Ex. : Révolution française, industrialisation, droits civiques, chute URSS, numérisation, IA (?)
- Illustration : salle de classe 1920 -> 1960 -> auj.

Théories (Suchanek)
- modernisation et transformation
- marxistes
- différenciation

Types de société (Suchanek) : postindustrielle, ==Risikogesellschaft==, multiculturelle, société mondiale

## Différenciation et anonymisation
- ==Ausdifferenzierung== : peu de sphères très imbriquées (religion, droit, écon., famille, pol.) -> bcp de sphères autonomes (science, art, éducation, médias, santé, armée…) -> armée = sous-système parmi d'autres
- ==Anonymisierung== : petite communauté où tt le monde se connaît -> société urbaine anonyme

## Gemeinschaft ≠ Gesellschaft ([[Ferdinand Tönnies]], 1855–1936)
| | ==Gemeinschaft== | ==Gesellschaft== |
|---|---|---|
| Relations | personnelles, « nous » | impersonnelles, anonymes |
| Orientation | coopération, but commun | intérêt propre, buts divergents |
| Lien | confiance, émotion, conviction morale | lois, sanctions, calcul fin-moyen |
| Composition | homogène | hétérogène |
| Unité | « organique », originelle | construite |
| Ex. | famille, amis, voisinage, village | grande ville, État, institutions, organisations |

-> [[Communauté et société]]

## Société moderne : 4 traits
1. changement rapide
2. individualisation, modernité
3. dépendance écon.
4. mondialisation, migration

## Après le cours
**En 3 phrases**
1. La sociologie étudie la vie en commun avec une distance critique ; l'armée est un domaine d'objet que l'on analyse comme une organisation prise dans la société.
2. Valeurs (le désirable, partagé) et normes (attentes contraignantes) créent l'ordre social, mais dans une société ouverte elles sont sans cesse remises en question.
3. Le changement social transforme la structure de la société (différenciation, anonymisation, passage de la Gemeinschaft à la Gesellschaft) — c'est le cadre de tout le cours.
