# Notes

## Intro : philo pol. (S. 7)
- ==Naturzustand== (Hobbes 1588-1679) : guerre de chacun contre chacun -> libre mais pas en sécurité
- ==Staatszustand== : État garant sécurité -> sûr mais pas libre
- Tâche originelle État : protection, sécurité <-> abandon de certains droits de liberté
- ==Abwehrrechte== (Rawls, Rousseau) ; gain : sécurité du droit, stabilité
- ?? citoyen per se unfrei ? (question ouverte du prof)

## Sécurité
- !! [[Sécurité objective et subjective]] (S. 9, 15)
  - objectif = ==Hellfeld== (crim. enregistrée), seulement un extrait (Schwind 2013)
  - subjectif = ==Dunkelfeld== + sécurité « ressentie » (Schwind 2013)
  - ?? Dunkelfeld = crim. réelle non enregistrée, pourquoi sous subjectif -> demander
  - pas de lien objectif / subjectif (Lange 2006, 323) ; rapport Hell/Dunkelfeld pas constant (Neubacher 2020)
  - matrice : objectif +/− × subjectif +/− -> echte / unechte Sicherheit / Unsicherheit
- Question ouverte (Ferst 2019) : 2258 réponses, 52 catég. -> sécurité définie surtout subjectivement
- !! [[Danger, risque et menace]] (BABS 2013, S. 11)
  - ==Gefahr== : indép. décisions d'acteurs ; pas calculable (forte pluie -> crue)
  - ==Risiko== : suite de décisions, sans viser tiers ; calculable (pluie, je sors, mouillé)
  - ==Bedrohung== : voulue par un acteur (terrorisme, extrémisme, crime org.)

## Changement du concept (S. 13-14)
- jusqu'au XVIIIe : politique ; dès XIXe : + sociale ; 1re moitié XXe : idéologique (après 46 USA/URSS) ; 2e moitié XXe : ==erweiterter Sicherheitsbegriff==
- !! [[Concept élargi de sécurité]] (Daase et Rühlig 2016) : 4 dimensions
  - Raum : national -> régional -> international -> global
  - Sach : militaire -> économique -> écologique -> humanitaire
  - Referenz : État -> société -> individu
  - Gefahren : Bedrohung -> ==Verwundbarkeit== -> Risiko
- !! Sicherheitsempfinden 2022 (S. 16) : 36 + 58 = 94 % sûrs ; Ø depuis 2012 : 32 + 60
- !! Maslow (S. 17) : besoins de base = sécurité écon. ; sécurité + relations = politico-sociale ; relations -> réalisation = psycho-spirituelle -> cf. [[Psychologie humaniste]]

## Liberté
- Déf. via contraire, Unfreiheit : contrainte, interdit, contrôle (Voigt 2012)
- Foucault : pouvoir disciplinaire ; Deleuze : société de contrôle (bracelets, vidéo)
- 2 sortes : ==Willensfreiheit==, ==Handlungsfreiheit==
- Cst. : droits fond., égalité + garanties, droits sociaux
- Art. 36 : base légale, intérêt publ., ==Verhältnismässigkeit== (Eignung, Erforderlichkeit, Zumutbarkeit), ==Kerngehalt== -> [[État de droit]]
- !! [[Liberté négative et positive]] (S. 22-23)
  - négative = Freiheit von : Abwehrrechte, opinion, mouvement
  - positive = Freiheit für : autodétermination
  - ?? slide met « absence de contraintes » sous positive -> classiquement négative (ajout : Berlin) -> vérifier Ferst 2019
  - question ouverte : 2262 réponses, 47 catég. -> surtout positive, liée à l'action

## Liberté vs sécurité
- Freiheitsstaat : libres, sécurité négligée ≠ Sicherheitsstaat : illibéralisme, actionnisme, contrôle ↑
- in dubio pro libertate ≠ in dubio pro securitate
- ==kein fixer Wechselkurs== (Denninger 2017) ; dosage jamais résolu (Gusy 2010, 115)
- « Sicherheit kostet Freiheit, aber ohne Sicherheit keine Freiheit » (Anter 2012, 137) ; Franklin 1755
- !! 3 thèses
  1. rapport ajusté sans cesse ; ==Zwillingspaar==
  2. ==Freiheitssicherheitskomplex== : préférence sécurité, asymétrique
  3. préférence liberté <- individualisation -> [[Changement de valeurs]]
- !! 2022 (S. 28-29) : sécurité 57 % (majoritaire dès 2016), liberté 45 % (minoritaire pr la 1re fois ; 04-18 Ø 57)
  - -> T1 + T2 confirmées pr 22, T3 non
  - ?? S. 29 : '18 = 57 % mais S. 28 = 56 ; '07 cité 2× (sans doute '02)
  - ajout : items séparés, pas choix forcé (2018 : 56 + 54 > 100)
