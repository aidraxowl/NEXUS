## Institution : déf.
- [[Institution]] = ==gesellschaftliche Erwartungsstrukturen==, « habitudes de la société »
- ==Institutionalisierung== = « objectivation » du comportement -> reconnu par tous comme allant de soi
- formelles (loi, mariage civil) ou informelles (usages)
- Fonction : ==Orientierungshilfe== -> agir sans tout renégocier (cf. [[Norme sociale]], fonction d'allègement)

## !! Institution ≠ organisation
| | ==Institution== | ==Organisation== |
|---|---|---|
| Époque | déjà sociétés traditionnelles | sociétés modernes |
| Action (Weber) | ==wertrational== | ==zweckrational== |
| Naissance | peut être spontanée | stratégique, voulue |
| Mécanisme | ==Habitualisierung== | ==Funktionalisierung== |
| Attente d'action | ==Gleichartigkeit== : tous font pareil | différenciation des rôles |

- Commun : ==Integrationsleistung== (intègrent les individus)
- -> armée = les deux : institution (valeurs, tradition, sens) + organisation (but, rôles, structure) ; garder pr V11

## Institutions et besoins de base
| Institution | Besoin soc. de base |
|---|---|
| Mariage / famille | relève (==Nachwuchs==) |
| École | formation, éducation hors famille |
| Économie | produire, distribuer les biens |
| Politique / État | décisions contraignantes |
| Religion | fondement ultime du sens (==Letztbegründung==) |

- Feldmann 2005 : institutions ≠ lieux / bâtiments, mais modèles de comportement, routines, systèmes de signes figés ; ds les têtes pourtant associées à des lieux (religion = église, pol. = Palais fédéral, éducation = école)

## Famille
- [[Famille]] : fonctions classiques = reproduction ; régulation de la sexualité (interdit de l'inceste) ; protection vers l'ext. ; transmission du statut soc. ; ==Geborgenheit== ; socialisation, éducation
- Indice synthétique de primo-nuptialité : ≈ 95 % (50s–60s) -> ≈ 50 % F / 45 % H (2025)
- Taux brut 2025 : ≈ 4 mariages, 1,7 divorce pr 1 000 hab.
- OFS : mariage de + en + remplacé ou précédé par d'autres formes (union libre, couple sans ménage commun, partenariat enregistré)
- Âge moyen 1er mariage : min. vers 1970 (≈ 26 / 24) -> 32,4 H / 30,7 F (2025)
- Divortialité : ≈ 12 % (1950) -> pic ≈ 54 % (2010) -> ≈ 39 % (2025)
- ?? creux brutal en 2000 : nouveau droit du divorce ? (à vérifier)
- Naissances hors mariage 2024 : CH ≈ 30 % (bas en Europe) ≠ UE-27 ≈ 41 %, France / Norvège ≈ 60 %
- Idéal familial : solidarité entre générations (aide financière, soins aux parents) + attendue en Suisse italienne et romande qu'alémanique
- Désir d'enfant : F 25–29 ans sans enfant -> la plupart en veulent 2 ; F 50–59 ans tertiaire : ≈ 30 % sans enfant -> écart désir / réalité, surtout chez les + formées (cf. [[Changement démographique]])

## Économie et travail
- Secteurs 1850 -> 2000 : primaire ≈ 58 % -> ≈ 4 % ; secondaire pic ≈ 49 % vers 1960 -> ≈ 26 % ; tertiaire ≈ 10 % -> ≈ 69 %
- Travail « traditionnel » : emploi sûr (CDI), revenu régulier, horaires de jour, protection soc., un employeur, organisation claire
- Taux d'emploi 2023 (OCDE) : CH ≈ 81 %, 3e derrière Islande et Pays-Bas ; écart H / F visible
- Plusieurs emplois : ≈ 4 % (1991) -> ≈ 8 % (2025) ; F ≈ 10,5 %, H ≈ 6 %
- Chômage : pics déflation (≈ 1921), Grande Dépression (≈ 1936), crise immobilière (90s) ; ≈ nul 1945–1975 ; sept. 2026 : 3 %
- [[Flexibilisation du travail]] (==neue Arbeitsverhältnisse==) : temps partiel, CDD, petits boulots, nuit / équipes, dimanche, temps de travail annuel, plusieurs employeurs, ==working poor==
- Temps partiel (Swiss Life 2019) : 37 % des actifs -> « nation du temps partiel », 2e en Europe après Pays-Bas ; mères 96 % le souhaitent / 51 % le font ; pères 87 % / 19 %
- Conséquences − : perte de réseaux soc., risque d'endettement, + d'emplois à bas salaire, inégalité ↑, mobilité ↑ -> perte d'identité possible
- Conséquences + : conciliation vie pro / privée, + d'alternatives pro.

## Politique
- Conseil national 1971 -> 2023 : bloc bourgeois + droite ≈ 63 % -> ≈ 59 % ; gauche + Verts ≈ 26 % -> ≈ 29 % ; UDC ≈ 11 % -> ≈ 28 % (recomposition à l'intérieur du bloc bourgeois)
- Participation : élections ≈ 80 % (1919) -> < 50 % ; votations ≈ 40–45 % ; CN 2023 : 46,6 %

## Religion
- 1970 : ≈ 98 % catholiques ou réformés
- 2024 : sans appartenance ≈ 37 % (1re catégorie) ; catholiques ≈ 30 % ; réformés ≈ 19 % ; communautés islamiques et autres chrétiennes ↑
- -> sécularisation : religion perd son monopole de la Letztbegründung

## Lien avec l'armée (mes notes)
- Armée = institution (sens, valeurs, défense de la collectivité) + organisation (but, rôles)
- Travail flexible, temps partiel, plusieurs employeurs -> conciliation avec le service de milice + difficile
- Akademisierung -> diplôme civil = référence ; officier de carrière fait un bachelor
- Ancrage ↓ ds institutions trad. (Église, partis, mariage) -> plus de consensus « allant de soi » pr l'armée -> pression de légitimation

## Après le cours
**En 3 phrases**
1. Une institution est une structure d'attentes stabilisée (habitude objectivée) qui oriente l'action ; elle se distingue de l'organisation, moderne, créée stratégiquement autour d'un but et de rôles différenciés.
2. Chaque grande institution (famille, école, économie, État, religion) répond à un besoin de base, et toutes changent : moins de mariages, plus de diplômés, travail flexible, participation faible, sécularisation.
3. Pour l'armée de milice, ces changements réduisent ce qui « va de soi » et compliquent la conciliation entre service, travail et famille.
