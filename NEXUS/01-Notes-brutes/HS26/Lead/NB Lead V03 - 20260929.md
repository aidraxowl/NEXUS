## 1. Doctrine (==Doktrin==)
- Les solutions dans le Command sont de nature **conceptuelle**. La doctrine peut soutenir, **tant qu'elle ne restreint pas** !!
- Bonne doctrine = montre **comment** les chefs peuvent agir avec succès, **pas ce qu'ils doivent faire** !!
- Command (conduite centrée sur la mission) s'établit dans la doctrine ; approche déterminante en Suisse : ==Auftragstaktik== -> [[Conduite par objectifs]].

### Stratégie
- ==PMESII== : l'environnement stratégique = système composé de facteurs dans 6 domaines : politique, militaire, économie, social, information, infrastructure (Vuitel, Hofstetter & Grangier 2025).
- « Rivalité systémique 2.0 » : démocraties libérales (force du droit, qualité, libéralisme, hétérogénéité, liberté, fédéralisme) ≠ régimes autoritaires (droit du plus fort, quantité, étatisme, homogénéité, contrôle, centralisme).

### Stratégie militaire : le débat suisse (Braun & Bühlmann 2006) -> [[Débat sur la conception de la défense suisse]]
- « Mobiles » (élèves de Wille) : armée = domaine autonome dans la société ; défense mobile à forte composante offensive ; courant international dominant ; faible importance du terrain ; objectif opératif : victoire / anéantissement (tradition prusso-allemande).
- ≠ « Statiques » (réformateurs de l'armée) : « nation armée » (peuple et armée) ; défense statique, étendue, échelonnée (points d'appui, barrages) ; forme spécifiquement suisse ; ancrage dans le territoire ; objectif : **usure et gain de temps**.
- Lignes historiques (d'après R. Jaun) : peuple en armes / orientation nationale ≠ nouvelle orientation Wille ; armée de citoyens ≠ armée de soldats ; modèle Prusse-Allemagne ≠ modèle États-Unis / OTAN (réformes Oswald).

## 2. Attrition Warfare et Manoeuvre Warfare
- Doctrine britannique 1996 : la manœuvre applique la force (feu) **contre la faiblesse** ≠ l'usure applique la force **contre la force** !!
- Sun Tzu (3.07) : 10× -> encercler ; 5× -> attaquer ; 2× -> diviser ; égal -> pouvoir combattre ; inférieur -> pouvoir se défendre ; sans commune mesure -> pouvoir l'éviter.
- Hofstetter, Borioli & Flemming (TMAF 2024) !! :
  - **Thèse I** : ennemi perçu plus faible -> **manœuvre** ; égal -> **usure** ; plus fort -> **guérilla**.
  - **Corollaire Ia** (nature) : guérilla = dynamique ; usure = **statique** ; manœuvre = dynamique.
  - **Corollaire Ib** (style de commandement) : guérilla et manœuvre -> ==mission command== ; usure -> ==detailed command==.
  - Déplacements stratégiques : ==hiding== (vers la guérilla), ==freezing== (vers l'usure), ==unfreezing==, ==intensifying== (vers la manœuvre).
  - **Thèse II** : les forces armées choisissent l'option **la plus à droite possible** du spectre pour exploiter leur avantage compétitif.
  - **Corollaire II** : les **innovations** ouvrent de nouvelles opportunités -> condition pour « dégeler » une guerre d'usure.

## 3. Auto-similarité (==Selbstähnlichkeit==)
- Chaos à toutes les échelles… mais **structure** à toutes les échelles (galaxie M101 ≈ ouragan Mitch : même forme spirale, échelles sans commune mesure).
- En tactique, les mêmes paires se retrouvent à chaque échelon !! : attaque/défense, feu/mouvement, statique/dynamique, usure/manœuvre, principes d'engagement…

## Après le cours
**En 3 phrases**
1. La doctrine établit le Command : une bonne doctrine montre comment agir avec succès, pas ce qu'il faut faire, et en Suisse elle repose sur la conduite par objectifs.
2. La manœuvre applique la force contre la faiblesse, l'usure la force contre la force ; selon le rapport de forces perçu, on choisit guérilla, usure ou manœuvre, avec un style de commandement correspondant.
3. Les mêmes oppositions tactiques se retrouvent à toutes les échelles (auto-similarité), et l'innovation est la condition pour sortir d'une guerre d'usure figée.
