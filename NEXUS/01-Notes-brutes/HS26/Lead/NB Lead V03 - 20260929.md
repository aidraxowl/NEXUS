## 1. Doctrine (==Doktrin==)
- solutions ds le Command = nature conceptuelle
- !! doctrine peut soutenir, tant qu'elle ne restreint pas

## 2. Attrition Warfare et Manoeuvre Warfare
- !! doctrine brit. 1996 : manœuvre = force (feu) contre la faiblesse ≠ usure = force contre la force
- Sun Tzu (3.07) : 10× -> encercler ; 5× -> attaquer ; 2× -> diviser ; égal -> pouvoir combattre ; inférieur -> pouvoir se défendre ; sans commune mesure -> pouvoir l'éviter
- !! Hofstetter, Borioli & Flemming (TMAF 2024) :
  - Thèse I : ennemi perçu + faible -> manœuvre ; égal -> usure ; + fort -> guérilla
  - Corollaire Ia (nature) : guérilla = dynamique ; usure = statique ; manœuvre = dynamique
  - Corollaire Ib (style de cdmt) : guérilla + manœuvre -> ==mission command== ; usure -> ==detailed command==
  - déplacements stratégiques : ==hiding== (-> guérilla), ==freezing== (-> usure), ==unfreezing==, ==intensifying== (-> manœuvre)
  - Thèse II : forces armées choisissent l'option la + à droite possible du spectre -> exploiter leur avantage compétitif
  - Corollaire II : innovations -> nouvelles opportunités -> condition pr « dégeler » une guerre d'usure

## Après le cours
**En 3 phrases**
1. La doctrine établit le Command : une bonne doctrine montre comment agir avec succès, pas ce qu'il faut faire, et en Suisse elle repose sur la conduite par objectifs.
2. La manœuvre applique la force contre la faiblesse, l'usure la force contre la force ; selon le rapport de forces perçu, on choisit guérilla, usure ou manœuvre, avec un style de commandement correspondant.
3. Les mêmes oppositions tactiques se retrouvent à toutes les échelles (auto-similarité), et l'innovation est la condition pour sortir d'une guerre d'usure figée.
