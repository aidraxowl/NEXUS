## 1. Classe : un concept contesté -> [[Classe sociale]]
- citations d'ouverture :
  - George Orwell (1941) : Angleterre = pays le + « class-ridden » ; système de classes pas seulement l'argent -> « shadowy caste-system », bungalow moderne hanté par des fantômes médiévaux
  - Margaret Thatcher (1986) : classe = concept communiste qui dresse les gens les uns contre les autres
  - Tony Blair (1998) : « take class out of politics »
  - Boris Johnson (2013) : élites + inégalité = moteur (« spirit of envy »)
- sondage *The Economist* 2006 :
  - 59 % pensent finir ds la même classe que leurs parents
  - indicateurs cités : métier, lieu de vie, ==Akzent==, revenu
  - 64 % trouvent facile de situer qqn par son parler et son ==Habitus==
- !! classe comme ==soziale Formation== (Marx / Engels, *Manifeste* 1848) :
  1. aristo propriétaires terriens -> rente foncière
  2. bourgeois / capitalistes -> revenus d'affaires
  3. prolétaires -> salaire
  - ==Klasse an sich== ≠ ==Klasse für sich== -> formation d'une ==Klassenbewusstsein== décisive
  - !! MAIS problème pr l'histoire brit. : pas de révolution
- !! ==Dekonstruktion== :
  - historiens soc. : simplification -> perméabilité des frontières + conflits internes
  - historiennes féministes : absence de la dimension genre
  - postmodernes (==linguistic turn==) : méfiance envers les « grands récits » -> classe = catégorie d'auto-classement et d'auto-représentation
  - -> dès 1990 la classe passe de mode en histoire
  - [[David Cannadine]] (2008) = critique de l'orthodoxie marxiste
- revenus annuels moyens Angleterre ~1890 :
  - peerage 30 000 £ · banquiers / industriels 10 000 £
  - avocats, fonctionnaires, cadres 500–2 500 £
  - enseignants, petits employés 130–400 £
  - ouvriers qualifiés 50–200 £
  - soldats, marins, non qualifiés 20–50 £
- classe comme ==soziale Ordnung== mi-XIXe :
  1. aristocratie (peerage + gentry) : env. 3 % de la pop., mais élite pol. + écon.
  2. classes moyennes 10–15 % : large spectre, petits paysans -> industriels, artisans urbains, clergé
  3. classes inférieures = travail physique : petits paysans / ouvriers agricoles + prolétariat industriel naissant
- !! -> « classe » = catégorie imprécise + hétérogène, mais importante comme ==soziale Identität==

## 2. Classe et politique (1850–1930)
- affiche Labour ~1910 : créer une conscience de classe ?
- working classes :
  - prolétariat industriel naît ds les 3 premières décennies du XIXe
  - 1870–1900 : identité de classe bcp + nette <- grandes unités écon. -> ==Erosion des betrieblichen Paternalismus==
  - syndicats : 750 000 membres (1888) -> 4 Mio (1913)
  - jeunes ouvriers de Sheffield, grève de Liverpool (1911)
- !! MAIS tensions entre « ==rough== » et « ==respectable== » working classes
  - après ==Reform Acts== 1832, 1867, 1884 -> presque tous les ouvriers votent -> rôle pol. important -> cf. [[Droit de vote]], [[Chartisme]]
  - intérêts représentés par le Labour Party, fondé 1900 -> processus ==dialogisch== de formation des identités de classe
  - affiches Labour (1931) vs Tory (1909) : perceptions opposées du conflit de classes
- !! pourquoi pas de radicalisation malgré la conscience de classe ? -> [[Aristocratie ouvrière]]
  - situation écon. relativement stable 1850–1900 -> prospérité
  - stratification de la classe ouvrière -> ==working class aristocracy==
  - ==social control== : écoles, institutions religieuses, patrons paternalistes, sport + loisirs
  - alliance stratégique avec la middle class sur bcp de questions -> profil pol. faible (affiche Labour « Liberale Agenda ? »)
- upper classes :
  - restent importantes écon., culturellement, politiquement loin ds le XXe
  - mode de vie aristo imité par la bourgeoisie : maisons de campagne, chasse, sport
  - siège garanti à la Chambre des lords -> position privilégiée jusqu'en 1911
  - « flexible ==gentlemanly capitalists== » -> encore la + grande part de la fortune brit. ds les 1920s -> [[Capitalisme gentlemanly]]
  - écoles privées + armée = identité des gentlemen ; public schools = « ==character factory== » (Harrow 1862, Eton 1875) ; cricket -> « gentlemanly qualities »

## 3. Débuts de la culture de masse : consommation, loisirs, sport
- ==Konsum== :
  - 1870–1900 : changements énormes pr les travailleurs -> ==Freizeit== revalorisée
  - 1871 ==Bank Holidays Act==
  - 1874 : semaine de 56,5 h -> temps de travail nettement ↓
  - salaires réels > +35 %
- !! ==multiples== dès 1870s : Lipton, Home and Colonial, Marks & Spencer -> [[Révolution du commerce de détail]]
  - achat en gros -> ==Branding== ; prix fixes + paiement comptant ; personnel non qualifié ; prod., gros et détail sous un même toit
  - -> « ==retail revolution== » : couches inf. accèdent aux biens de luxe
- Lipton :
  - corner shop à Glasgow ds les 1870s ; spécialisation thé
  - 250 magasins (1898) -> 3 000 (1929)
  - prix bas <- standardisation, ==Lohndumping==, contrôle de toute la chaîne
  - -> particularités régionales de mode + consommation disparaissent (produits de marque nationaux)
- jusqu'au milieu XIXe : shopping de luxe = upper + upper middle classes seulement
  - prod. de masse, vitrines, ==Department Stores== -> vers 1900 consommation = phénomène de masse (chaussures Clark's, pianos « industriels » 1910)
  - ==Branding and advertising== : pubs calibrées pr des « target groups »
  - ~1900 : Harrod's, Lewis's, Selfridge's -> shopping = loisir surtout pr les femmes (window shopping)
  - achat à crédit + vente par correspondance -> cercle des consommateurs ↑
  - !! nouvelle culture de conso sape en partie la séparation des classes : montre de poche, « Sunday clothes », piano chez les ouvriers -> « ==masher menace== »
- ==Freizeit== :
  - dernier tiers XIXe : séparation + stricte travail / loisir ; repos vu comme utile au rendement
  - patrons, Églises, syndicats critiques envers loisirs établis (blood sports, jeu, beuveries)
  - !! -> ==rational recreation== : musée, zoo, bibliothèques, musique, éducation des adultes -> [[Loisirs rationnels]]
  - années 1880 : grande industrie des loisirs
  - !! ==Music Hall== = pilier de la culture ouvrière + petite middle class : chansons, variétés, travestis, acrobatie, alcool ; grandes salles jusqu'à 3 000 places (Bristol) ; stars Hetty King, Marie Lloyd, Jules Léotard
  - fin : cinéma + jazz -> music halls transformés en cinémas ; 1914 déjà 4 000 « picture palaces » ; jazz 1920s = coup de grâce
- ==Tourismus== :
  - salaires ↑ + transports publics -> excursions à la mer
  - 1914 : 80 % des familles ouvrières peuvent s'offrir une excursion d'un jour, 20 % une nuitée
  - Brighton, Bournemouth, Blackpool (station principale de la working class) ≠ destinations pr « men of class » (continent, Asie)
- ==Sport== -> cf. [[Amateurisme]], [[Origines du sport]]
  - ~1770–1870 : « ==Sportization== » (A. Guttmann selon le script)
  - jeux d'équipe improvisés + « ==blood sports== » (combats de coqs, de chiens, boxe sans règles) remplacés peu à peu par formes + « civilisées » (Cruelty to Animals Act 1835)
  - professionnalisation + « amateurisation », règles codifiées
  - quelques blood sports survivent tard : « rat baiting » (~1875)
  - foot : populaire ds public schools + Oxbridge ; règles codifiées 1863
  - clubs subventionnés par industriels (Manchester United, Liverpool) et Églises (Aston Villa)
  - 1886 : FA accepte la professionnalisation
  - spectateurs 1re division : ~5 000 (1880s) -> 25 000 (1914)
  - !! -> diffusion + ==Kommerzialisierung== de l'idéal sportif « gentlemanly »
  - cricket garde son image gentleman (Cambridge 1899), mais commercialisé aussi : W. G. Grace pub pr lessive (1892)
- !! nouvelles cultures de loisir + conso peuvent aussi ==reproduzieren== les différences de classe :
  - entrées séparées ds les grands magasins
  - destinations touristiques différentes
  - sports « gentlemanly » ≠ « vulgar »
  - -> frontières érodées en partie, mais symboles de statut restent aussi importants qu'avant
- !! classe jusqu'au XXIe = réseau complexe de facteurs socioculturels :
  - spatial (habitat), social (amis, choix du conjoint), linguistique (accent, vocabulaire), habitus (vêtements, loisirs), physique (santé dentaire)
  - élites pol. : 65 % du cabinet Sunak (2023) ont fréquenté une école privée ≠ 7 % de la pop.
