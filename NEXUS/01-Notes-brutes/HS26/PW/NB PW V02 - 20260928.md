# Notes

## 2.1 Logique et buts
- science ≠ savoir quotidien ou croyance (enjeu à l'ère des fake news)
- ==Politische Theorie== (philo pol.) ≠ ==politikwissenschaftliche Theorien== !!
- empirie + analyse se complètent
  - énoncé logique non confirmé (« la droite est peu instruite »)
  - observation sans argument (cigognes -> naissances) -> ==Scheinkorrelation==
- but principal !! : énoncés logiquement cohérents ET empiriquement confirmés sur relations cause-effet ([[Causalité]])
- question de recherche : délimite l'objet ; efficace si elle réduit la complexité
- théorie = énoncés confirmés par plusieurs études, généralisables, plausibles
  - cygnes blancs -> un seul cygne noir = ==Falsifikation== (Popper)
  - ?? p. 63 le livre appelle « Deduktion » la dérivation de régularités empiriques, mais p. 77 : déduction = du général au particulier -> retenir p. 77
- 3 ontologies (Lichbach 1997) !!
  - ==rationalistisch== : intérêt propre, stratégies
  - ==kulturalistisch== : valeurs et normes = « Kitt » (Putnam)
  - ==strukturalistisch== : conditions de vie (ouvriers -> gauche, paysans -> partis agrariens)
- structuralisme -> pb de [[Microfondement]] : les structures n'agissent pas -> ==kausaler Mechanismus== macro-micro-macro (Coleman)
  - ex. Weber : éthique protestante -> ascèse intramondaine -> éthique du travail -> capitalisme !!
- théorie = système d'énoncés cohérents (déf., ==Prämissen==) avec plusieurs hypothèses, certaines testables
  - image du « filet » ; bateau de Campbell (on change qq planches en se fiant aux autres)
- [[Inférence]] (King et al. 1994) : du connu vers l'inconnu ; ==generalisierbar== = valable pr tous les cas couverts par l'argument
- concepts (Sartori, Goertz) -> déf. ni vraies ni fausses, mais claires et reproductibles
- [[Hypothèse]] -> relation entre concepts ; ==AV== (Explanandum, Y) / ==UV== (Explanans, X)
  - rôle dépend de l'étude (Politikverdrossenheit UV ou AV)
- causalité rarement linéaire (Pierson) : délais, seuils, Scheinkorrelation (variable tierce), réciprocité
  - incertitude jamais nulle ; expériences > études observationnelles

## 2.1.2 Règles du jeu
- ==Nachvollziehbarkeit== : documenter, rendre données et code dispo -> ==Replikation== ; langue précise
- ==Ehrlichkeit== : ni fabriquer, ni taire les résultats contraires ; plagiat = vol intellectuel
- falsification = moteur du progrès (Popper 1935) ; résultats tjs provisoires ; communiquer l'incertitude !!

## 2.2 Déroulement (10 étapes) !!
1. Question 2. Argument théorique 3. Hypothèses 4. Définitions 5. Opérationnalisation 6. Forme de recherche 7. Sélection des unités 8. Collecte 9. Analyse 10. Publication
- fil rouge : Tsebelis, [[Joueur de veto]], lockdowns -> [[Lockdowns Covid-19 et joueurs de veto]]

### 2.2.1 Question
- sources : lacune, débat théorique, thème oublié, transfert d'une théorie
  - ==empirisches Rätsel== : OGM (Europe stricte, USA souples malgré richesse comparable)
  - ==theoretisches Rätsel== : paix démocratique (explications concurrentes)
- 5 critères !!
  1. formulée comme question (descriptive ou causale ; causale + exigeante)
  2. positive, pas normative (« L'Ukraine doit-elle entrer ds l'UE ? » ≠ testable ; pronostic OK) ; gare au biais ethnocentrique
  3. délimitée (≠ « rôle de l'UE ds l'écon. mondiale »)
  4. analysable (contrefactuel Bush/Irak -> modèles, simulations ; données dispo ?)
  5. pertinence soc. et scientifique

### 2.2.2 Argument théorique
- nains sur des épaules de géants ; revue de littérature pertinente, complète, critique (Annual Review, peer review, éditeurs ; vérifier ce que donne l'IA)
- théorie = projecteur ; plusieurs théories -> l'empirie arbitre ; bonne théorie = ==Sparsamkeit== (parsimony)
- théories générales (rational choice, théorie des systèmes) ≠ ==Theorien mittlerer Reichweite== (dominantes, + précises, portée limitée)
- ==deduktiv== (général -> particulier) ≠ ==induktiv== (particulier -> général) ; en pratique va-et-vient !!
- modèles = simplifications (plan de métro) : verbaux, ==Pfeildiagramm== (+/−), math., simulations, régression
- veto players : agenda-setter veut déplacer le statu quo ; moins de VP ou VP + homogènes -> changement + facile

### 2.2.3 Hypothèses
- descriptive (part des non-votants ↑) ≠ causale
- ==X-zentriert== (une UV centrale + ==Kontrollvariablen==) ≠ ==Y-zentriert== (toutes les causes d'un Y -> risque de [[Biais de variable omise]], besoin de bcp d'observations)
- 3 critères !!
  1. dérivée de la théorie, sens de l'effet (si-alors, plus-plus)
  2. ==Varianz== sur UV et AV, sinon constante ; covariance ≠ causalité
  3. falsifiable (==Nullhypothese==)
- Tsebelis : écart idéologique entre VP ↑ -> lois importantes ↓
- Covid : H1 gvt + à gauche -> lockdown + strict ; H2 VP nombreux et hétérogènes -> lockdown - strict

### 2.2.4 Concepts
- les concepts doivent « voyager » ; ==Extension== (cas couverts) vs ==Intension== (attributs) : relation inverse = [[Échelle d'abstraction]] (Sartori ; Collier/Mahon) !!
- ==Overstretching== : « constitution » pr tout État -> « les constitutions empêchent la dictature » n'a plus de sens
  - « korporativer Pluralismus » (Rokkan, Norvège) : généraliser en gardant le noyau
- veto player = concept très général (voyage bien) ; « stabilité pol. » = maintien du statu quo, non normatif

### 2.2.5 Opérationnalisation
- concept -> variable -> ==Indikatoren== -> ==Index==
  - ex. démocratie : élection du législatif, de l'exécutif, alternance, compétition (Abb. 2.6)
- échelles !! : ==dummy/binär== · ==ordinal== (écarts inégaux) · ==metrisch== (écarts égaux)
- [[Validité et fiabilité]] !!
  - fiabilité = même résultat à répétition (thermomètre > ressenti)
  - validité = on mesure bien le concept (déf. large avec égalité H/F -> indicateurs ci-dessus trop courts)
- Covid : OxCGRT (9 mesures) ; positions gauche-droite des VP -> écart max. ; position de l'agenda-setter

### 2.2.6 Forme de recherche
- expérience = forme de base : le chercheur intervient ; groupe traité ≠ contrôle ; ==treatment== binaire ; [[Randomisation]] -> ==interne Validität== !!
  - labo (interne ↑, externe ↓) ≠ terrain (campagne intensifiée ds circonscriptions tirées au sort)
  - limites éthiques (priver d'école)
- ==Quasi-Experiment== : événement quasi aléatoire (loi, catastrophe : canicules, inondations -> soutien à la pol. climatique) ; méthodes stat. qui simulent traitement et contrôle (accord de Paris)
- non expérimental : variance obtenue par la stat. ou par le choix des cas (Lijphart 1975)
- quanti !! : grand N, instruments standardisés, données secondaires (Polity −10/+10)
  - \+ bcp de cas (externe ↑), procédure structurée (transparence, réplication), incertitude chiffrée
  - − processus difficiles à chiffrer, foi ds les chiffres, simplification excessive (AUS, DK, UK tous à 10)
- quali !! : peu de cas, en mots ; ==process tracing==, ==pattern matching==
  - \+ infos riches, mécanismes, interne ↑
  - − peu généralisable + ==Überdeterminiertheit==, risque d'« arguing by illustration », réplication difficile
  - Bennett/Checkel : « cast the net widely »
- ==Mixed methods== (Lieberman) : quanti puis quali (cas déviants) ou l'inverse
- choisir : imaginer l'expérience idéale (si impossible -> hypothèse douteuse), puis s'en approcher

### 2.2.7 Sélection des unités
- ==Grundgesamtheit== (pop. théorique) ≠ ==Stichprobe== ; ==Vollerhebung==
- ==Zufallsstichprobe== : 1000–2000 suffisent ; taille selon complexité et homogénéité, pas selon taille de la pop.
- ==Quotenstichprobe== : minorités rares
- petit N : méthode comparative ; idéal 10–20 cas par variable (souvent 4–5 en comparaison de pays)
- ==Most Similar Systems Design== !! : cas semblables sur var. tierces, différents sur X et Y
  - ex. CAN vs UK pr fédéralisme -> déficit (pas IND vs UK)
- ≠ ==Most Different Systems Design== : tester une hypothèse ds des systèmes différents, ne comparer qu'en cas d'échec
- études de cas : mécanismes internes au cas (process tracing, narratifs analytiques)
- [[Biais de sélection]] (Geddes 1990) !!
  - [[Biais de sélection|Sondage du Literary Digest]] 1936 ; Hirschman sur le Chili (période 1930–61 mal choisie)
  - quali + exposé ; remède : cas très différents sur X
- Covid : 39 démocraties « libres » (FH) − Chili, Malte, Israël, Corée du Sud (données manquantes) = 35

### 2.2.8 Collecte
- ==Befragung== : standardisée, semi-structurée (guide), non structurée ; experts ; écrite ou orale ; World Values Survey, ISSP
- ==soziale Erwünschtheit== + réponses stratégiques (frais d'études) !! -> ==Beobachtung== (bancs du parc ; ouverte/cachée, participante ou non)
- ==Inhaltsanalyse== (Comparative Manifesto Project ; analyse automatisée de textes)
- ==Sekundärdaten== (Polity, Banque mondiale) : vérifier d'abord ce qui existe

### 2.2.9 Analyse
- hypothèse probabiliste ≠ déterministe (un seul cas contraire suffit : paix démocratique)
- régression Covid (35 démocraties, contrôle : infections)
  - modèle 1 (fin mars 2020) : R² ≈ 0,63 ; position du gvt significative (+1,264 par point, jusqu'à env. 30 points), VP non
  - modèle 2 (fin juin 2020) : R² ≈ 0,25 ; VP hétérogènes -> lockdown + faible (≈ ⅓ de l'écart, USA max.)
- lire une régression !! : ==signifikant== (étoiles, p < 0,05) ≠ ==substanziell== (taille du coefficient) ; R² et R² ajusté ; test F ; constante non interprétée
- tests quali (Van Evera) : ==straw in the wind== < ==hoop== (exclut) < ==smoking gun== (clair, pas certain) < ==doubly decisive==
- ==QCA== (Ragin) : conditions nécessaires et suffisantes

### 2.2.10 Publication
- ==Peer review== anonyme (accept / reject / revise & resubmit) ; contrôle qualité central, mais modes, subjectivité, réseaux
- ==graue Literatur== à lire + critiquement ; conférences, working papers

## Après le cours
**En 3 phrases**
1. La recherche empirico-analytique veut des énoncés causaux logiquement cohérents et empiriquement confirmés, toujours provisoires et falsifiables.
2. Elle suit dix étapes, de la question à la publication, où définitions, opérationnalisation (validité, fiabilité) et sélection des cas décident de la qualité.
3. Le choix de la forme (expérience, quanti, quali, mixte) est un arbitrage entre validité interne et externe, à faire selon la question et les données.
