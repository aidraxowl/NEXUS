# Notes — Kap. 3

## 3.1 Système politique
- [[Système politique]] (Holtmann 1994) : ensemble des institutions et acteurs étatiques ET non étatiques, règles et procédures qui formulent et résolvent les problèmes et produisent des décisions contraignantes !!
- Citoyens (base) -> ==Intermediäre== (partis, groupes, mouvements, médias) -> ==zentrales Entscheidungssystem== (législatif, exécutif, judiciaire) ; ==Input== (demandes, soutien, opposition) -> ==Output== (lois, jugements) -> rétroaction
- Démocratie : input citoyen plus fort + pouvoirs plus séparés ≠ autocratie : pouvoir concentré dans une petite élite

## 3.2 Démocratie
- Grec : pouvoir du peuple ; Lincoln 1863 : *of / by / for the people*
- Athènes (5e–4e s. av. J.-C.) : assemblée de tous les citoyens mâles majeurs (sans femmes ni esclaves) ; ==Rat der 500== tiré au sort pour un an ; tribunaux citoyens -> démocratie directe
- Aujourd'hui représentative <- taille, distances, complexité ; principe conservé : ==Volkssouveränität== !!
- 2 traits clés !! : (1) transfert du pouvoir par élections libres et équitables (régulières, universelles, égales, libres, directes, secrètes) (2) mandat limité dans le temps
- Dahl 1971 : ==Wettbewerb== + ==Partizipation== ; élections -> changement pacifique (Przeworski) + effet disciplinant
- [[Démocratie]] étroite (Schumpeter, Przeworski, ACLP : élections + compétition + alternance) ≠ large (Dahl, Diamond : + libertés, sources d'info, État de droit, minorités…) -> plus large = plus dur d'étudier les effets (critères = conséquences ?) !!
- DE (Art. 20 GG, « streitbare Demokratie »), AT (Art. 1 B-VG), CH (préambule) ; AT semi-prés., DE parl., CH mixte + démocratie directe ; CH pondère la participation, DE/AT les droits fondamentaux contre la majorité
- UE : démocratie condition d'adhésion (Art. 2 TUE, Hongrie) ; Exkurs 3.1 déficit démocratique : BVerfG Lisbonne 2009 (pas d'égalité de vote) ; Moravcsik 2002 (pas de déficit) ≠ Follesdal & Hix 2006 (déficit : pas de compétition, pas de demos)

## 3.3 Autocraties
- Point commun !! : pas d'élections libres pouvant mener à l'alternance ; pouvoir aux mains d'un petit groupe
- Spectre : Singapour (libertés, peu de participation) <-> Corée du Nord (totalitaire)
- Typologie (Cheibub et al. 2010 ; Geddes et al. 2014) : 3 types + 2 dimensions [[Autocratie]] !!
  - ==Monarchie== : absolue (Arabie saoudite ; Vatican élective) · constitutionnelle = autocratique (Maroc : décrets ; Jordanie : veto surmontable aux 2/3) · parlementaire = démocratique : le monarque ne peut ni révoquer le gouvernement ni dissoudre le parlement !!
  - ==Militärregime== : junte ; Argentine 1976–83 -> [[Régime militaire argentin]]
  - ==Zivilregime== : parti unique (Chine, PCC depuis 1949) · parti dominant (élections manipulées : « defekte Demokratien », Merkel ; « competitive electoral autocracies », Levitsky/Way ; Iran, Russie, Biélorussie)
- 1946–2010 : partis uniques ↓ après Guerre froide, militaires ↓ après 1990, monarchies stables, personnalistes ↑ (Erdoğan, Maduro, Xi)
- ==Personalisierung== : Irak de Saddam (militaire très personnalisé), Cuba (personnalisé + parti) ≠ Mexique PRI 1929–2000 (président 6 ans, pas de réélection)
- ==Freiheitsbeschränkung== : extrême = totalitarisme (Arendt : idéologie + terreur ; nazisme, stalinisme, Corée du Nord) !!

## 3.4 Mesures !!
- [[Démocratie|Mesure de la démocratie]] : ACLP (binaire, étroite) · V-Dem (0–1, moyenne, 5 indices) · Polity (−10/+10) · Freedom House (1–7, 1 = libre, large)
- ACLP et Polity ignorent la participation ; FH néglige les institutions ; discret ≠ continu (Collier/Adcock 1999) ; aucun indice parfait -> choix = question de validité ; robustesse = refaire l'analyse avec un autre indice
- Écarts entre indices surtout pour les cas de la zone grise : Inde (faible chez V-Dem), Turquie (calendriers différents) ; Pologne consensuelle
- Exkurs 3.2 backsliding : Little & Meng 2024 (biais des codeurs) ≠ Knutsen et al. 2024 ; V-Dem : ¾ de l'humanité en autocratie, 45 pays en autocratisation

## 3.5 Effets du type de régime
- Valeur procédurale + performance -> ==Input-== vs ==Output-Legitimität== (Lipset, Scharpf)
- Démocraties -> plus de biens publics : 2 explications, même prédiction, mécanismes différents !!
  1. [[Électeur médian]] (Meltzer/Richard 1981) : en démocratie médian plus pauvre -> redistribution ↑ ; limite : les pauvres votent moins (Gilens)
  2. [[Bien public]] vs privé : non-exclusion + non-rivalité, coût fixe ; privé : coût croît avec les bénéficiaires -> grande base -> biens publics
- Exkurs 3.3 [[Théorie du sélectorat]] (Bueno de Mesquita et al. 2003) : sélectorat S, winning coalition W ; W grande -> biens publics ; W petite + S grand -> loyauté forte, biens privés -> élite riche, pays pauvre
- Éducation : préférence pour l'école publique ↓ avec le revenu ; objections (pauvres votent moins, classe moyenne veut université : Ansell, Brown/Hunter) ; Abb. 3.4 (131 pays, 2022) : lien positif mais sans contrôles, causalité inverse possible ; Stasavage 2005 (primaire ↑ en Afrique) ; Lake/Baum 2001 (analphabétisme ↓)
- Croissance : pour (sécurité juridique Olson 1993 ; prévisibilité Feng 2003 ; éducation Baum/Lake 2003) ≠ contre (pression redistributive, coalitions distributives Olson 1982) ; Barro 1996 non linéaire ; Acemoglu et al. 2019 : la démocratie cause la croissance
- Exkurs 3.4 pauvreté : Gerring et al. 2012 (mortalité infantile, effet du « stock » de démocratie) ; Halleröd & Ekbrand 2023 (démocratie + tradition de gauche)

## 3.6 Démocratisation
- 1815 ~3 % de démocraties -> aujourd'hui ~la moitié ; libérales ↓
- Vagues de Huntington !! : 1828–1926 / contre-vague 1922–42 / 1943–62 / contre-vague 1958–75 / depuis 1974 (Portugal, Espagne, Grèce…) ; aujourd'hui 3e vague d'autocratisation (91 autocraties vs 88 démocraties)
- 6 voies (Schmidt 2019) : externe libérés (NL, FR, BE) · externe imposée (RFA, AT, JP) · interne pactée par le régime (Espagne -> [[Transition démocratique espagnole]]) · imposée par l'opposition (Pologne, Hongrie) · effondrement (Indonésie, URSS) · révolution (Serbie 2000, Philippines 1986)
- [[Théorie de la modernisation]] (Lipset 1959) : développement -> éducation, urbanisation, classe moyenne -> demande de participation ; Przeworski/Limongi 1997 : endogène ≠ exogène -> seule l'exogène tient (le développement stabilise) !! ; Acemoglu et al. 2008 ; Rueschemeyer et al. 1992 (structure sociale) ; islam et démocratie contesté (Teti et al. 2019)
- Difficultés : peu de cas, processus complexes

## Après le cours
**En 3 phrases**
1. La démocratie se définit au minimum par des élections libres permettant l'alternance ; les autocraties se distinguent par leur type (monarchie, militaire, civil), leur degré de personnalisation et de restriction des libertés.
2. Les démocraties fournissent plus de biens publics (électeur médian, sélectorat) et le développement les stabilise plus qu'il ne les crée.
3. Parmi les démocraties, la séparation horizontale (parlementaire/présidentiel) et verticale (fédéralisme) des pouvoirs détermine le nombre de joueurs de veto et la capacité de réforme.
