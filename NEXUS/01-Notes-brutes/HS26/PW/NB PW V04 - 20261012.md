# Notes

## 5.1.1 Fonctions des élections
- ==Wahl== = procédure de sélection qui forme un organe ou désigne un dirigeant ; plus légitimante que l'hérédité ou la nomination
- Autocraties : pas de compétition ; stabiliser le pouvoir, mobiliser, montrer la solidarité avec l'élite (forte participation, résultat net) ; vitrine démocratique sous pression extérieure !!
- Abb. 5.2 (Nohlen) : démocratie (choix et liberté élevés, la question du pouvoir est posée, légitimation) · autoritaire (faibles, non, légère) · totalitaire (nuls, non, non)
- Démocratie : recrutement compétitif = trait constitutif ; date d'introduction du suffrage = âge d'une démocratie
- Histoire !! : d'abord hommes, quotas selon classe ou fortune ; ordre typique (Rokkan) : vote secret -> suffrage masculin -> suffrage féminin ; CH : hommes 1848, femmes 1971 (123 ans plus tard)
- ==aktives Wahlrecht== (voter) ≠ ==passives Wahlrecht== (être élu) !! ; âge 18 (AT : 16 depuis 2007) ; UE : depuis 1992 vote des ressortissants UE aux communales et européennes (éligibles aux européennes) au lieu de résidence ; retrait : crimes graves, maladie empêchant la libre formation de l'opinion
- Tendances : vote à 16, Suisses de l'étranger, vote par correspondance, e-voting, early voting
- [[Droit de vote]] : 5 conditions !! : ==allgemein==, ==gleich==, ==frei==, ==direkt==, ==geheim== + régularité (6e critère) -> délégation limitée dans le temps et contrôle

## 5.1.2 Caractéristiques des systèmes électoraux
- Plus faciles à changer que les autres institutions (==electoral engineering==) -> forte variété : pas deux pays identiques !!
- 4 aspects !! : découpage des circonscriptions · offre et expression du vote · conversion voix -> sièges · obligation de voter ou de s'inscrire -> [[Système électoral]]
- ==Wahlkreiseinteilung== : NL, ISR 1 circonscription ; FR 577, UK 650 ; DE 299 ; AT 1 + 9 + 39 ; CH 26 cantons
  - ==Wahlkreisgröße== = facteur décisif : circonscription à 1 siège -> avantage aux grands partis !! ; NL 150 sièges -> 0,67 % suffit = ==natürliche Sperrklausel== -> [[Système électoral|Seuil électoral]]
  - Inégalités de taille (Brésil 1986 : 4500 vs ~500 000 voix par siège) ; ==Gerrymandering== (Elbridge Gerry 1812, salamandre) ; ==Malapportionment== par l'évolution démographique
- Offre : candidatures individuelles ou listes ==starr== (DE Zweitstimme -> dépendance au parti ↑), ==lose gebunden==, ==frei== (CH : ==Kumulieren==, ==Panaschieren==)
- Conversion : ==Majorz== (relative/simple ou absolue) ≠ ==Proporz== (D'Hondt favorise légèrement les grands, Sainte-Laguë, Hare-Niemeyer)
- ==formelle Sperrklausel== !! <- crainte de trop de partis -> instabilité : DK 2 %, AT 4 %, DE 5 %, TR 10 % ; CH aucune
- ==Wahlpflicht== (BE, LU, AUS -> participation forte ; IT sans sanction -> peu d'effet ; NL abolie dans les années 1970) ; ==Meldepflicht== (USA, UK, IRL -> participation ↓)

## 5.1.3 Classifications
- [[Système électoral|Scrutin majoritaire]] -> majorités stables, responsabilité claire (UK, USA) ≠ [[Système électoral|Représentation proportionnelle]] -> représentation équitable, réactivité, nouveaux partis (NL)
- ==manufactured majority== (Rae) !! : majorité des sièges avec < 50 % des voix ; UK 2024 Labour 34 % des voix -> 63 % des sièges ; Reform UK 14 % -> 1 % -> Élections britanniques de 2024
- ==spurious majority== : le 2e parti en voix obtient la majorité (Australie 1954, 1961, 1969 ; USA 2000, 2016 en présidentielle) ; ==earned majority== ; ==natürliche Minderheit==
- Abb. 5.3 (Lijphart, 36 démocraties 1945–96) : majoritaire 43,7 % majorités fabriquées vs PR 9,4 % ; natural minority 17,2 % vs 82,3 %
- Exkurs 5.1 : FPTP (UK, USA, CAN, IND) · deux tours (Conseil des États, présidentielle FR) · vote alternatif (AUS chambre basse) · PR de liste (le plus répandu : Scandinavie, AT, NL, CH Conseil national) · STV (IRL, MLT, Sénat AUS) · mixte (DE jusqu'en 2023, NZ ; segmenté IT depuis 1994, sans compensation)
- Passage au PR <- Boix 1999 : partis établis craignant la montée socialiste ; aussi selon la structure économique (besoin de consensus avec les minorités) ; NZ -> PR personnalisée ; IT -> mixte (90s)
- ==Disproportionalität== -> ==Gallagher-Index== : SE 0,6 ; AT 3,2 ; DE 3,5 ; CH 3,6 ; IRL 7,8 ; GR 9 ; UK 23,6 (2024) ; mesurer un système majoritaire au critère de proportionnalité est inapproprié
- Majoritaire : gouvernements plus durables (Dodd) -> chaque système atteint son objectif

### Effets (Abb. 5.4) !!
- Électeurs : majoritaire -> vote pour/contre un gouvernement, rétrospectif ; PR -> vote pour un représentant, prospectif ; PR -> participation plus élevée (sentiment d'équité) malgré l'offre plus complexe
- Élus : majoritaire -> stratégie ==bridging==, dépendance à la circonscription ↑, au parti ↓ -> discipline plus difficile ; PR -> ==bonding==, dépendance au parti ↑
- Gouvernement : majoritaire -> parti unique, stabilité, responsabilité claire, alternance plus probable ; PR -> coalitions ou ==Minderheitsregierung== (tolérée tant qu'aucune majorité ne s'y oppose), alternance partielle (DE 1949–98 : FDP partenaire junior)
- Partis : [[Système électoral|Effets mécaniques et psychologiques]] (Duverger) : majoritaire -> bipartisme, PR -> multipartisme ; « loi » tendancielle, pas déterministe
- Société : seuil élevé -> minorités dispersées non représentées ; sociétés à nombreux clivages et minorités dispersées -> PR (Lijphart 1977) ; homogènes -> majoritaire possible

## 5.2 Démocratie directe, représentative, semi-directe
- Pure directe : pas de parlement (Athènes) -> Démocratie athénienne
- Typologie Hug/Tsebelis (Abb. 5.5) !! : (1) obligatoire ou non ? (2) déclenché par le gouvernement ? (3) sur une décision existante ou une nouvelle demande ? -> ==obligatorisches==, ==Regierungs-==, ==fakultatives Referendum==, ==Volksinitiative== -> [[Démocratie directe|Référendum]], [[Démocratie directe|Initiative populaire]]
- Référendum facultatif (Abb. 5.6) !! : l'utilité des réformateurs ↑ avec l'ampleur du changement, mais la probabilité de succès d'un référendum des opposants ↑ aussi (plus vite si opposition forte) -> compromis plus proche du statu quo ; obligatoire -> encore plus proche du SQ, le gouvernement perd plus rarement
- Obligatoire constitutionnel le plus répandu (CH, AUS, certains États US) ; facultatif constitutionnel (IT, AT, RO, UY) ; législatif (IT, DK, CH)
- Référendum gouvernemental : FR Art. 11 ; AT ; UE 2005 (FR, NL rejettent) ; adhésion UE 1994, « stratégie des dominos » (AT, FIN d'abord ; marche en SE, pas en NO) ; buts : vérifier le soutien, déplacer la responsabilité, forcer l'opposition à se positionner, surmonter les divisions internes -> [[Référendum sur le Brexit]] !!
- Initiative = ==Gaspedal== ≠ référendum facultatif = ==Bremse== ; CH seul pays avec initiative constitutionnelle nationale ; lancée par les partis des marges, rarement du centre !!
- 4 fonctions (Linder/Müller) !! : soupape (« révolution légale ») · succès indirect (contre-projet, monnaie d'échange) · catalyseur (agenda) · mobilisation interne / aide électorale
- Abb. 5.7 : arbitrage chances de succès ↔ degré d'innovation ; petite coalition homogène -> point idéal loin du SQ
- Exkurs 5.3 : DE quasi purement représentative (Art. 29, 146 GG ; Bade-Wurtemberg 1951/52, Berlin-Brandebourg rejeté 1996) ; AT : Volksbefragung (jamais au niveau fédéral), Volksabstimmung (Zwentendorf 1978 non, UE 1994 oui), Volksbegehren (106 depuis 1964, ≈ pétition) ; CH : obligatoire (double majorité peuple + cantons), facultatif (50 000 signatures ou 8 cantons en 100 jours, majorité du peuple), initiative (100 000) ; 1848–2024 : obligatoires 73 % acceptés, facultatifs ~59 %, initiatives < 10 % (26/234)
- Origines : Rousseau, Condorcet + Landsgemeinden ; vagues 1800–1939 et depuis 1970 ; CH en 3 phases cantonales (1830s, ~1850, 1860s mouvement démocratique) ; fédéral : 1874 facultatif, 1891 initiative partielle, 1921 traités, 2003 initiative générale
- Peut aggraver les conflits : Californie (bipartisme polarisé -> contournement du compromis) ≠ CH (multipartisme collégial -> compromis) -> instruments non transposables !!

## 5.3 Fazit
- Majoritaire = stabilité + responsabilité ; PR = représentativité + réactivité
- Référendums -> rapprochement du statu quo + intégration des groupes forts ; référendum gouvernemental = instrument de pouvoir ; initiative = innovation mais faible succès
- Élections ≠ votations : postes ≠ questions de fond ; régularité ≠ irrégularité

## Après le cours
**En 3 phrases**
1. En démocratie, les élections posent la question du pouvoir et doivent être universelles, égales, libres, directes, secrètes et régulières ; en autocratie elles stabilisent le pouvoir.
2. Scrutin majoritaire et proportionnelle poursuivent des buts différents (stabilité vs représentativité) et façonnent électeurs, élus, partis (Duverger) et gouvernements.
3. Référendums et initiatives ajoutent des joueurs de veto ou des accélérateurs : le référendum freine et intègre, l'initiative innove mais réussit rarement.
