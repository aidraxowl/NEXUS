# Notes

## Marktversagen = justification des interventions -> [[Défaillance du marché]]
- !! au moins 6 raisons pr un marché qui fonctionne mal :
  1. ==unvollständiger Wettbewerb==
  2. ==öffentliche Güter==
  3. ==Externalitäten==
  4. ==unvollständige Information==
  5. ==Umverteilung== et ==meritorische Güter==
  6. ==Arbeitslosigkeit==, ==Inflation==, ==Ungleichgewicht==
- biens publics : le marché privé ne les offre pas, ou trop peu (défense nationale, phares, air, médecine préventive) -> [[Bien public]]
- externalités :
  - négative : qqn impose des coûts aux autres sans compensation (air, bruit, eau polluée)
  - positive : qqn apporte un bénéfice aux autres sans être payé (jardin fleuri, régions de montagne)
  - -> allocation par le marché ineffic.
- info incomplète : ==Informationsasymmetrie== peut faire disparaître un marché
  - ==Adverse Selection== : ex. assurances
  - ==Moral Hazard== : être assuré -> incitation ↓ à éviter le sinistre
- redistribution : marchés concurrentiels -> revenus inégaux ; argument = valeurs soc. ≠ efficacité ; ==Existenzminimum== ; décision normative -> choix pol. -> [[Efficacité et équité]], [[Énoncé positif et énoncé normatif]]
- ==meritorische Güter== : le marché pourrait les offrir, mais l'État les offre car consommation jugée part. souhaitable (formation, santé)
  - critère = justice soc., pas efficacité
  - « ==Service public== » -> production publique ou privée

## Question du chapitre
- déjà vu : offre + demande -> prix et qté d'équilibre ; chocs -> déplacement des courbes -> [[Équilibre de marché]]
- maintenant : effets de ==Höchstpreise==, ==Mindestpreise==, ==Steuern==, ==Subventionen==

## Preiskontrollen -> [[Contrôle des prix]]
- introduits qd politiques jugent les prix injustes pr acheteurs ou vendeurs
- ==Höchstpreis== (price ceiling) : prix max légal auquel un bien peut être vendu
- ==Mindestpreis== (price floor) : prix min légal

## Höchstpreis -> [[Contrôle des prix]]
- 2 cas :
  - !! ==nicht bindend== : plafond au-dessus du prix d'équilibre -> aucun effet
  - !! ==bindend== : plafond en dessous du prix d'équilibre
- ex. glace : équilibre 3 € / 100 boules
  - plafond 4 € -> sans effet
  - plafond 2 € -> offre 75, demande 125 -> pénurie de 50
- bindend -> ==Mangelwirtschaft== (==Nachfragelücke==) : QD > QS
  - ex. RDA, pénurie d'essence aux USA années 1970
- -> ==Rationierung== (« ==non-price-rationing== ») : files d'attente, discrimination par les vendeurs

## Fallstudie : files aux stations-service -> [[Contrôle des prix]]
- 1973 : OPEP ↑ prix du pétrole
- pq des files ? -> économistes : plafond sur l'essence fixé par le gvt sous le prix d'équilibre
- graphe : (a) au départ plafond au-dessus de P1 -> sans effet ; (b) offre ↓ (S1 -> S2) -> plafond devient bindend -> excédent de demande QD > QS
- !! même plafond, d'abord inoffensif, devient bindend après un choc d'offre

## Mindestlohn -> [[Contrôle des prix]]
- ex. important de prix plancher : ==gesetzlicher Mindestlohn== (USA, France)
- (a) sans salaire min : ==Gleichgewichtslohn==, ==Gleichgewichtsbeschäftigung==
- (b) salaire min > salaire d'équilibre -> offre de travail > demande -> ==Angebotsüberschuss== = chômage

## Steuern -> [[Incidence fiscale]]
- questions : effet sur l'équilibre ? qui porte la ==Steuerlast== (acheteurs et/ou vendeurs) ?
- !! après taxe : acheteurs paient + , vendeurs reçoivent −, peu importe sur qui la taxe est prélevée
- ==Steuerinzidenz== = répartition de la charge fiscale entre acteurs

## Taxe sur les acheteurs -> [[Incidence fiscale]]
- ex. glace, taxe 0,50 € : demande D1 -> D2, vers le bas de 0,50 €
- avant : 3,00 €, 100 boules ; après : acheteurs paient 3,30 €, vendeurs reçoivent 2,80 €, 90 boules
- -> acheteurs portent 0,30, vendeurs 0,20
- effets : activité du marché ↓, chiffre d'affaires du bien ↓, charge partagée

## Taxe sur les vendeurs -> [[Incidence fiscale]]
- même taxe : offre S1 -> S2, vers le haut de 0,50 €
- !! résultat identique : 3,30 / 2,80 / 90 boules

## Wohlfahrtseffekte einer Steuer -> [[Perte sèche]]
- graphe chiffré (S. 26) : demande P = 10 − q ; offre sans taxe P = q ; avec taxe P = q + 2 (taxe = 2)
  - sans taxe : P = 5, q = 5
  - avec taxe : q = 4 ; acheteurs paient 6, vendeurs reçoivent 4
- aires (mes calculs, pas sur le slide) :
  - nouvelle ==Konsumentenrente== = ½ × 4 × 4 = 8 (avant 12,5)
  - nouvelle ==Produzentenrente== = ½ × 4 × 4 = 8 (avant 12,5)
  - ==Steuereinnahmen== = 2 × 4 = 8
  - ==Wohlfahrtsverlust durch Steuer== = ½ × 2 × 1 = 1 (triangle entre q = 4 et 5)
  - contrôle : 25 = 8 + 8 + 8 + 1 ✓

## Subventionen -> [[Subvention]]
- déf. : paiement de l'État à acheteurs ou vendeurs pr encourager la conso d'un bien dont on produit trop peu
- en général versée aux vendeurs
- coûts de production ↓ (≠ taxe : coûts ↑) -> équilibre change
- ex. trajets en train, subvention 20 € par trajet : offre S1 -> S2, vers le bas de 20 €
  - sans subvention : 75 €, Qe ; avec : acheteurs paient 60 €, Q1 > Qe
  - vendeurs reçoivent 60 + 20 = 80 € (déduit, pas écrit sur le slide)
- acheteurs paient −, vendeurs reçoivent +
- !! coûts : directs (budget) + indirects (==Überproduktion==)

## Article NZZ (S. 30) : « Tankhilfe vom Staat schadet »
- commentaire de B. Triebe, NZZ, 23.09.2026 ; contexte : DE baisse la taxe sur l'essence, carburant cher en CH
- arguments : aide aux automobilistes payée par tous les contribuables (aussi train, vélo) ; arrosoir -> mieux aider de façon ciblée les ménages pauvres
- !! idée centrale : le prix sert à orienter les comportements -> prix élevé doit freiner la demande
- baisser le prix -> retarde l'adaptation, freine efficacité et alternatives, protège le concurrent qui n'a pas anticipé
- lien avec le cours : prix plafond / subvention -> signal-prix faussé

## Zusammenfassung (VL S. 31–33)
- plafond sous l'équilibre (ex. ==Mietpreisbindung==) -> rationnement
- plancher au-dessus de l'équilibre (salaire min) -> excédent d'offre et rationnement
- taxe -> Q d'équilibre ↓ ; ==Keil== entre prix payé par l'acheteur et prix reçu par le vendeur
- subvention aux vendeurs -> coûts ↓, production ↑, acheteurs profitent de prix plus bas
- taxe -> bien-être des acheteurs et des vendeurs ↓ ; perte de SC + SP en général pas compensée par les recettes fiscales
- ==Nettowohlfahrtsverlust== <- on produit et consomme moins, le marché rétrécit
- !! taille de la perte dépend des ==Preiselastizitäten== de l'offre et de la demande -> [[Élasticité]]
