> [!abstract] L'essentiel
> Ce chapitre (dimension Command du CLM) montre que le Command s'établit dans la doctrine, qui doit montrer comment agir avec succès sans restreindre. La forme de guerre choisie (guérilla, usure, manœuvre) dépend du rapport de forces perçu et appelle un style de commandement (mission command ou conduite détaillée). Les mêmes oppositions tactiques se répètent à toutes les échelles.

^essentiel

## Fil logique
1. Command -> doctrine -> en Suisse, conduite par objectifs.
2. Contexte : stratégie (PMESII, rivalité systémique) et débat stratégique suisse (mobiles vs statiques).
3. Usure (force contre force) ≠ manœuvre (force contre faiblesse).
4. Thèses : rapport de forces perçu -> stratégie -> nature -> style de commandement ; innovation pour dégeler.
5. Auto-similarité : on retrouve ces paires à chaque échelon.

## Schéma
- Ennemi perçu plus fort / égal / plus faible -> guérilla / usure / manœuvre -> dynamique / statique / dynamique -> mission / detailed / mission command.

## Questions de synthèse
> [!question]- Pourquoi une doctrine fondée sur la conduite par objectifs est-elle cohérente avec la thèse II ?
> Si les armées cherchent à aller vers la manœuvre (dynamique), elles ont besoin de mission command ; une doctrine prescriptive enfermerait dans la conduite détaillée propre à l'usure.
